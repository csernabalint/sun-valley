# Hallmark Redesign (Structural Re-Skinning)

In an early-phase project, initial wireframes often feel clumsy or slide into generic templates. `hallmark-redesign` strips out the flawed layout geometry and swaps it for a fresh, high-conviction macrostructure without altering a single word of your approved marketing copy or technical data.

---

## 1. Operating Rules

1. **Copy Preservation Guarantee**: Do not modify headings, subtext, technical specs, or CTA labels unless explicitly instructed.
2. **Structural Swap**: Change the entire spatial arrangement:
   * Transform an alternating left/right layout into an asymmetric bento grid.
   * Transform a flat list into a multi-column industrial spec sheet.
3. **Audit Against 57 Gates**: Ensure the redesigned version complies with all anti-slop rules.

---

## 2. Redesign Procedure

1. **Extract Content Inventory**:
   * Text blocks (H1, H2, body, footnotes).
   * Data points (Brix, pH, packaging sizes).
   * Actions (Form inputs, sample request buttons).
2. **Select New Macrostructure**:
   * Choose a contrasting structural archetype (e.g. from linear card stack to dense split dashboard).
3. **Rebuild Geometry**:
   * Implement the new layout using Sun Valley CSS variables.
4. **Side-by-Side Review**:
   * Verify that no content was dropped and that visual density is improved.
